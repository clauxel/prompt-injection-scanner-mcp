# Security Notes

PromptGuard Scan is designed for LLM security testing and MCP access is token-gated.

## Token handling

- Store MCP tokens in your client's secret storage or environment-specific configuration.
- Do not include tokens in public GitHub issues, logs, prompt transcripts, support screenshots, or docs.
- Rotate a token if it has been exposed.

## Responsible disclosure

If you believe you found a vulnerability in the hosted service, email support@aigeamy.com with a concise reproduction and impact description. Do not include customer data or secrets.
