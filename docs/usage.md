# Usage

PromptGuard Scan MCP is a remote paid MCP server. After checkout, claim an MCP token and configure your client with the remote endpoint.

## Endpoint

```
https://promptguardscan.space/mcp
```

## Authorization header

```
Authorization: Bearer <token>
```

## Typical workflow

1. Buy a PromptGuard Scan plan on the website.
2. Claim the MCP token after payment confirmation.
3. Add the Streamable HTTP endpoint to your MCP client.
4. Run security status, scan-readiness, pricing, analytics, or checkout-support tools from the client.

Keep tokens out of source control, public issues, terminal recordings, prompt transcripts, and screenshots.
